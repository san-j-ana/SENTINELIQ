# SentinelIQ – AI-Powered Fraud Detection & Risk Analytics Platform

## Overview

SentinelIQ is a Java Full Stack application designed to detect potentially fraudulent financial transactions using intelligent risk analysis. The platform provides real-time transaction monitoring, fraud prediction, and security insights through a modern dashboard.

The application combines Artificial Intelligence concepts with Java Full Stack technologies to help financial institutions identify suspicious transactions and reduce fraud risks.

---

## Features

- Secure User Login & Registration
- AI-Based Fraud Risk Analysis
- Transaction Monitoring Dashboard
- Fraud Risk Score
- Transaction History
- Search & Filter Transactions
- Fraud Analytics Dashboard
- Security Recommendations
- REST API Integration
